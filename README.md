# Description
This is a basic todo list website allow user to plan his day in an organized manner.

# Features
<ul><li>User can add task at anytime according to his wish.</li>
<li>User can mark status of tasks whether it is completed or not.</li>
<li>User have choice to delete the task whenever required.</li></ul>

# Technologies_used
This website is developed using HTML, CSS and javascript.
